## 1. Introduction
This guide explains **how to use the Flask Blog Platform** in clear, simple terms.  
It is designed for **clients, product owners, managers, and non-technical stakeholders**.

No programming knowledge is required to understand or use this application.

---

## 2. What This Application Does
The application is a **simple blog management system** with an administrative interface.

With it, you can:
- Create and manage users
- Create blog posts and assign them to users
- Publish or keep posts as drafts
- View overall platform statistics

---

## 3. How the Application Is Organized
The application has **two main parts**:
- A web-based admin interface
- A background system that safely stores information

You only interact with the **web interface**.

---

## 4. Getting Started
1. Make sure the system is running
2. Open the admin page in your browser
3. Use the tabs at the top to navigate

---

## 5. Using the Application

### 📊 Statistics Dashboard
Shows:
- Number of users
- Number of posts
- Number of published posts

Used to quickly understand platform activity.

---

### 👥 User Management
Allows you to:
- Add new users
- View all users
- Remove users

Deleting a user also removes their posts.

---

### 📝 Post Management
Allows you to:
- Create posts
- Choose an author
- Publish or keep as draft
- Remove posts

---

## 6. Typical Usage Scenarios
- Create users → create posts → publish
- Draft content → review → publish
- Clean up old users and posts

---

## 7. Data & Safety
- Passwords are protected
- Data is saved automatically
- No login system in this version

---

## 8. Things Good to Know
- Users must exist before posts
- Statistics help verify actions
- Can be expanded later

---

## 9. Summary
A simple, easy-to-use platform for managing blog content.
