
# Flask Blog Platform – Training Handout & Demo Script

## Objective
Demonstrate the full usage of the platform in under 15 minutes.

---

## Demo Flow (Suggested)

### Step 1 – Open the Platform
- Open the admin interface in the browser
- Point out the three main tabs:
  - Statistics
  - Users
  - Posts

---

### Step 2 – Statistics Tab
- Show current numbers
- Explain this is a real-time overview
- Click "Refresh"

Talking Point:
> “This gives a quick snapshot of platform activity.”

---

### Step 3 – Create a User
- Go to **Users**
- Create a new user

Talking Point:
> “Users represent authors of blog posts.”

---

### Step 4 – Create a Post
- Go to **Posts**
- Select the user
- Create a draft post
- Create a published post

Talking Point:
> “Posts can be reviewed as drafts before publishing.”

---

### Step 5 – Review Results
- Return to Statistics
- Confirm numbers changed

---

## Key Messages to Emphasize
- Very easy to use
- No technical skills required
- Ideal for demos and testing workflows

---

**End of Training Script**
