## 15-AI-doc-generation
Using AI to quickly generate an application  User Guide for the application 

### AI-Assisted

This section of the project focuses on applying AI techniques to **AI-powered Documentation**.

#### Objectives

1. Quickly produce the application user guide 
2. The document should be in Markdown format
3. The document should explain to a Client, Product Owner, QA Analyst or all other stakeholders who want to understand how to use the application

#### Tools & Technologies

1. **AI Models:**  Online ChatGPT 5.2
2. **Frameworks:** Markdown format

#### How proceeded

1. Using ChatGPT 5.2 directly online 
2. Context files : app.py, index.html
3. 1st prompts using RCTEFT format  (see PROMPTS.md)
4. Following AI recommendation, other prompts used to generate more useful information
5. Multiple Markdown documents have been generated 
6. Markdown files grouped in a DOCX file 
7. Quick revision by me on the generated DOCX document

#### Results

A really quick generation of a good document that really helps multiple stakeholders (PO,QA,Dev etc.) to understand the usage, the technicality, the functionality of the application.

* PROMPTS.md - The interactions I had with AI
* *.md - The markdown files generated by IA 
* Flask_Blog_API.docx - The Word document created from the markdown files 

### My AI Discoveries 

With the use of AI, we can produce application documentation very easily and quickly, directly from the code.

The AI ​​understood what I wanted in terms of documentation, but also understood the application itself and suggested/guided me to introduce highly relevant content for stakeholders.

A huge saving in documentation time.
