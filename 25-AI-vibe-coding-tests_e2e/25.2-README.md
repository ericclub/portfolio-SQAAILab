## 25-AI-vibe-coding-tests-e2e  
  
### AI-Assisted  
  
This section of the project focuses on applying AI techniques to **AI vibe coding focused on e2e automated tests**.  
  
### Objectives  
  
The goal of this phase was to complete the first tests suites for the 'Flask Blog' lab application (10-AI-vibe-coding) with end-to-end automated tests, which were proposed and approved in the previous analysis phase (20-AI-QA-analysis-assistant).  

### Tools & Technologies  

1. **AI Models:** Claude Opus 4.5 (GitHub Copilot)
2. **Frameworks:** Selenium WebDriver 4.x, Pytest, webdriver-manager
3. **Backend:** Flask REST API (Python)
4. **Frontend:** HTML/CSS/JavaScript
5. **Browsers:** Chrome (default)
  
### How I Proceeded  
  
1. I used as context 10-AI-vibe-coding\result and 20-AI-QA-analysis-assistant\result  
2. I used a strong precise prompt using the RCTEFT format (Role, Context, Tasks, Example, Format, Tone)  
   See 25-AI-vibe-coding-tests_e2e/context/PROMPTS.md  
3. I used Claude Opus 4.5 (pro mode activated)
