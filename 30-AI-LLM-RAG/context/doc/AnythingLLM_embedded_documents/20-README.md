## 20-AI-QA-analysis-assistant

### AI-Assisted

This section of the project focuses on applying AI techniques to **AI-powered QA Analysis**.

### Objectives

Since The application currently has no automated tests, user stories, acceptance criteria, test cases, we need a document that define: 

1. Summarize what the software is for and its structure
2. User Stories, Acceptance Criteria and test cases  
3. Test Strategy / test types (Unit tests, Integration tests, e2e Tests, Test Pyramid..)

### Tools & Technologies

1. **AI Models:** GPT 5.2
2. **Frameworks:** Gherkin format, Markdown Format, Python & HTML code 

### How proceeded

1. VSCode Chat set to GPT 5.2
2. Writing a good RCTEFT format prompt (see PROMPTS.md) 
3. Revision of generated document 
4. Adjusting/Adding Prompt information 
5. Revision of generated document approved 

### Results

QA Analysis document generated : user_stories.md 

### My AI Discoveries 

In the context of analyzing application specifications and testing strategies, AI is a very powerful tool for significantly optimizing the production of these tasks.

These tasks took me less than 30 minutes instead of, for example, 2 days.
It was easy to review the informations and ask for adjustement.

Using AI, I was able to produce in a few moments a very solid document in terms of best practices for quality assurance strategies.
