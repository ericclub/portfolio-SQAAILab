## 🇫🇷 Français

### 10-AI-vibe-coding
Utiliser l'IA pour générer rapidement une application web simple pour ce laboratoire

#### Assisté par IA

Cette section du projet se concentre sur l'application de techniques d'IA au **Vibe Coding**.

##### Objectifs

1. J'ai besoin d'une application web pour le laboratoire où je peux explorer l'assistance de l'intelligence artificielle dans un processus d'assurance qualité logicielle.
2. L'application peut être simple mais doit inclure du code backend, du code frontend et une base de données.
3. Les outils utilisés — code backend, code frontend et données — doivent être à la pointe de la technologie.
4. L'application doit être développée rapidement par un tiers (l'IA en utilisant le Vibe Coding).
5. Un guide d'installation doit être fourni.

##### Outils & Technologies

1. **Modèles d'IA :** VSCode - AI Chat - Claude Opus 4.5
2. **Frameworks :** Python, Flask, PyMySQL, HTML, CSS

##### Comment j'ai procédé

1. De bons prompts utilisant le format RCTEFT (voir PROMPTS.md)
2. Code généré par l'IA
3. Guide d'installation produit par l'IA
4. Installation effectuée par l'IA 
5. Installation testée manuellement par moi pour confirmer le guide d'installation
6. Vérification rapide du code pour comprendre la structure 
7. J'ai demandé à l'IA de m'assister pour implémenter des sous-répertoires afin de clarifier visuellement la structure du projet.
8. Ce fichier README.md au format portfolio a été proposé par l'IA afin que le lecteur puisse comprendre ce qui a été fait en quelques minutes

##### Résultats

```
10-AI-vibe-coding/  Dossier principal de cet usage de l'IA
   context/         Fichiers et Prompt utilisés comme contexte pour l'IA 
   result/          Génération assistée par l'IA
        app/        Application générée
        doc/        Documentation générée 
        others      Fichiers d'environnement générés pour l'application
```

* Flask Blog API
    * Une API backend RESTful (Python Flask + SQLAlchemy)
    * Une interface web d'administration légère (HTML/CSS + JavaScript)
    * Opérations CRUD complètes pour les utilisateurs et les articles de blog
    * Tableau de bord de statistiques globales
    * Voir /10-AI-vibe-coding/result/doc/INSTALL.md pour l'exécution

#### Mes découvertes IA 
    * Assistance au Vibe Coding
    * Assistance à la documentation 
    * Utilité de l'assistance Copilot alimentée par l'IA
