# Resume / CV Repository

This repository contains different versions of my CVs. These files are available to the public and can be viewed or downloaded as needed.

## Available CV Versions

- **Eric_Leblanc_CV.docx**: English Version
- **Eric_Leblanc_CV_ATS.docx**: Application Tracking System Version
- **Eric_Leblanc_CV_fr.docx**: French Version

## Usage

Feel free to view or download any of the CV versions listed above. Each version is tailored for different purposes:

- The **English Version** is the standard CV suitable for most applications
- The **ATS Version** is optimized for Applicant Tracking Systems used by many organizations
- The **French Version** (Version française) is provided for French-speaking opportunities

## Access

This repository is public, allowing anyone to view and download the files. Only the repository owner can modify the content to ensure the integrity and accuracy of the CVs.
