## 10-AI-vibe-coding
Using AI to quickly generate a simple web application for this lab

### AI-Assisted

This section of the project focuses on applying AI techniques to **Vibe Coding**.

#### Objectives

1. I need a web application for the lab where I can explore artificial intelligence assistance in a software quality assurance process.
2. The application can be simple but must include backend code, frontend code, and a database.
3. The tools used—backend code, frontend code, and data must be state-of-the-art.
4. The application must be developed quickly by a third party (AI using Vibe Coding).
5. An installation guide must be provided.

#### Tools & Technologies

1. **AI Models:** VSCode - AI Chat - Claude Opus 4.5
2. **Frameworks:** Python, Flask, PyMySQL, HTML, CSS

#### How proceeded

1. Good prompts using RCTEFT format (see doc/PROMPTS.md)
2. Code generated by AI
3. Installation Guide produced by AI
4. Installation done by AI 
5. Installation teste manually by me following to confirm/review the Installation Guide
5. Quick Manual testing verified by me to understand the app and detect bugs if their are 
6. Quick verification of the code to understand the structure 
7. I asked the AI ​​to assist me to implement subdirectories in order to visually clarify the project's structure.
8. This portfolio README.md format file have been proposed by AI so that the reader can understand what was done in a few minutes
