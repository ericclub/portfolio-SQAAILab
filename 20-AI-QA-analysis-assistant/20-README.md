## 🇫🇷 Français

### 20-AI-QA-analysis-assistant

#### Assisté par IA

Cette section du projet se concentre sur l'application de techniques d'IA à l'**analyse QA alimentée par l'IA**.

#### Objectifs

Étant donné que l'application n'a actuellement aucun test automatisé, user stories, critères d'acceptation ou cas de test, nous avons besoin d'un document qui définit : 

1. Un résumé de l'objectif du logiciel et de sa structure
2. Les user stories, critères d'acceptation et cas de test  
3. La stratégie de test / types de tests (tests unitaires, tests d'intégration, tests e2e, pyramide des tests…)

#### Outils & Technologies

1. **Modèles d'IA :** GPT 5.2
2. **Frameworks :** Format Gherkin, format Markdown, code Python & HTML 

#### Comment j'ai procédé

1. VSCode Chat configuré sur GPT 5.2
2. Rédaction d'un bon prompt au format RCTEFT (voir PROMPTS.md) 
3. Révision du document généré 
4. Ajustement/ajout d'informations au prompt 
5. Révision du document généré approuvée 

#### Résultats

Document d'analyse QA généré : user_stories.md 

#### Mes découvertes IA 

Dans le contexte de l'analyse des spécifications d'une application et des stratégies de test, l'IA est un outil très puissant pour optimiser significativement la production de ces tâches.

Ces tâches m'ont pris moins de 30 minutes au lieu de, par exemple, 2 jours.
Il était facile de revoir les informations et de demander des ajustements.

Grâce à l'IA, j'ai pu produire en quelques instants un document très solide en termes de bonnes pratiques pour les stratégies d'assurance qualité.

4. Adjusting/Adding Prompt information

#### Results

QA Analysis document generated : user_stories.md 

#### My AI Discoveries
